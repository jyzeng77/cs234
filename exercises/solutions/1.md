# Exercise 1 Solutions

## Question 1

```text
DELETE_ALL(M, Data)
INPUT: a multiset M and a data item Data
EFFECTS: Deletes all copies of Data from M
while IS_IN(M, Data):
    DELETE(M, Data)
```

## Question 2

1. **Preconditions:** M is a multiset, Data is any data item, and Data must be in M

    **Postconditions:** Deletes all copies of Data from M
2. **Preconditions:** M is a multiset and Data is any data item

   **Postconditions:** Deletes all copies of Data from M; if there are no copies of Data in M, M is unchanged
