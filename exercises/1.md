# Exercise 1

## Question 1

> Write a pseudocode function Delete All(M, Data) that uses the operations of the ADT Multiset to delete all copies of data item Data from the Multiset M. If there are no copies of the data item Data in M, then M is unchanged.

```txt
DELETE_ALL(M, Data)
Input: a Multiset M and any data item Data
Output: updated M
Effects: all instances of Data are removed from M if they exist

while IS_IN(M, Data):
    DELETE(M, Data)

return M
```
